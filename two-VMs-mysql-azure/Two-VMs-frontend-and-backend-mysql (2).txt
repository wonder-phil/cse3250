The FRONTEND VM has the public IP address.

Attached a public IP address to the FRONTEND.
Also, open port 22 for SSH on the FRONTEND.

Protocol: TCP

const mysql = require('mysql2/promise');

(async () => {
  const conn = await mysql.createConnection({
    host: '172.16.0.5',
    user: 'appuser',
    password: 'StrongPass123!',
    database: 'sampledb'
  });

  const [rows] = await conn.query("SELECT * FROM people");
  console.log(rows);
})();
